# Security policy

Made by Georgia Rachel. This educational/open-source starter is not a certified security product.

Report vulnerabilities privately to the repository owner using GitHub private vulnerability reporting if enabled. If unavailable, open a minimal issue asking for a private reporting channel without publishing exploit details, credentials or personal data. Do not attach live malware.

Supported source: current main branch only. No response-time or patch SLA is promised. Keep browsers updated. Review permission changes on upgrade. Aegis never bypasses Chrome/Edge dangerous-download decisions and never executes submitted files.

Trust boundaries and known limitations are described in `docs/architecture.md` and `docs/limitations.md`.
