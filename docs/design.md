# Dashboard design

Made by Georgia Rachel. Designed using the UI/UX Pro Max skill's dark monitoring-dashboard guidance.

The dashboard uses deep navy surfaces, mint protection accents, amber review signals and system fonts. Local system fonts avoid third-party font requests. Four numeric cards distinguish observed traffic, confirmed blocks, different-host requests and phishing signals. A native canvas chart has a parallel HTML data table. No invented background data or animated activity suggests protection that was not observed.

Navigation uses real anchors and landmarks. Inputs have visible labels; checkboxes and buttons remain keyboard accessible; focus rings, touch-sized targets, responsive columns and reduced-motion CSS are included. Status and errors use an aria-live region. The warning dialog uses explicit leave/proceed choices, plain-language risk explanations and creator credit.

Change semantic CSS tokens in `dashboard.css` to restyle the interface. Preserve contrast, visible focus and the Made by Georgia Rachel footer.
